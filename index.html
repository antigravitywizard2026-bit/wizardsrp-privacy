Política de privacidad

WizardsRP NEW GENERATION es un bot de Discord para comunidades de rol.

Datos

El bot puede procesar identificadores de usuario y servidor para ejecutar sus funciones.

Uso de datos

Los datos se utilizan para proporcionar las funciones del bot y mantener la seguridad del servicio.

Contacto y eliminación

Para consultar, corregir o solicitar la eliminación de datos, contacta con el responsable del bot a través de su servidor de soporte.
